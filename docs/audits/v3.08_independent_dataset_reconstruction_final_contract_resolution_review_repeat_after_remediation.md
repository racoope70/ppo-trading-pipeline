## 7. Nine-choice contract resolution

All nine required choices are resolved at the governance and documentation level.

### Choice 1 — Alpaca request surface

The contract binds the provider interface to Alpaca historical stock bars using:

```text
StockHistoricalDataClient
StockBarsRequest
get_stock_bars
TimeFrame.Hour
DataFeed.IEX
Sort.ASC
```

### Choice 2 — Corporate-action adjustment

The request is bound to:

```text
Adjustment.RAW
```

### Choice 3 — Warm-up request start

The raw request start is fixed as:

```text
raw_request_start = 2022-12-01T00:00:00Z
```

The contract requires at least 50 observed pre-contract bars per symbol, prohibits adaptive start-date movement, and requires fail-closed behavior when the warm-up requirement is not met.

### Choice 4 — Exchange calendar dependency

The selected dependency and calendar are:

```text
exchange-calendars==4.13.2
calendar = XNYS
```

Installation and runtime verification remain explicitly deferred to a future authorized implementation stage.

### Choice 5 — Time-zone semantics

The contract requires UTC-aware request timestamps, provider timestamps, calendar comparisons, and final serialized timestamps.

### Choice 6 — Hour-bar interval semantics

Bars are interpreted by open timestamp using the half-open interval:

```text
[t, t + 1 hour)
```

The entire interval must be contained within the selected XNYS session. Relabeling bars or creating a custom 09:30 aggregation is prohibited.

### Choice 7 — Missing and duplicate slot policy

The contract requires zero missing expected slots, prohibits synthetic bars, forward filling, interpolation, and other repair, rejects duplicates, and requires reporting followed by fail-closed termination.

### Choice 8 — Parquet engine

The writer is bound to:

```text
PyArrow 24.0.0
```

Pandas engine auto-selection and fastparquet fallback are prohibited.

### Choice 9 — Schema and writer profile

The contract fixes a 27-column Arrow schema and an explicit, complete Parquet writer profile. Schema order, types, nullability, metadata, and writer settings are governed rather than left to library defaults.

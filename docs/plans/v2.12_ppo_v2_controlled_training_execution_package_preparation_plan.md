## Future Command Contract

The future one-time command must remain no-submit:

```bash
python -m ppo_v2_controlled_training_execution \
  --mode controlled-training \
  --run-id <sealed_run_id> \
  --config artifacts/ppo_v2/package_preparation/<run_id>/config/controlled_training_config.yaml \
  --quarantine-root artifacts/ppo_v2/quarantine/<run_id> \
  --no-submit
```

The command must fail closed if any of the following appear:

```txt
--submit
--paper
--live
--controlled-submit
--promote
--ppo-rf
--ppo-xgboost
broker order submission path
paths outside quarantine
unsealed config
unsealed run id
unsealed source-of-truth context
dirty git state
main not equal to origin/main
missing sealed checkpoint tag
```

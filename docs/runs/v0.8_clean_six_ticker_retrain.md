## Interpretation

This v0.8 retrain produced a cleaner six-ticker PPO baseline because the model evaluation is now based on out-of-sample evaluation slices rather than the same rows used for training.

The results are mixed but useful:

```text
XOM performed strongly across all three windows.
UNH had two PPO-winning windows but one poor/high-drawdown window.
AAPL had one PPO-winning window and two Buy & Hold-winning windows.
AMD had one PPO-winning window but Buy & Hold dominated two windows.
MRK was weak overall except window 0-3500.
PFE was stable but low-return/low-Sharpe overall.
```

The retrain should be treated as a research baseline, not an immediate deployment selection.

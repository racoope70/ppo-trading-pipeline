The future execution must fail closed if:

- SIP entitlement is unavailable, uncertain, or requires unapproved cost or subscription changes;
- Alpaca credentials or account permissions are unclear;
- the API request contract cannot be frozen before execution;
- any source-code, test, requirements, dependency, or workflow change is required;
- any data output path is not predeclared;
- returned SIP rows do not exactly match the 66 target observations;
- SIP returns only partial target coverage;
- SIP timestamp semantics cannot be reconciled to the governed expected grid;
- SIP data quality or provenance cannot be documented;
- any non-target rows would be needed to make a candidate complete;
- any merge into IEX raw data would be required;
- any dataset generation would be required; or
- any validation, preflight, training, order, deployment, or tagging action would be required.

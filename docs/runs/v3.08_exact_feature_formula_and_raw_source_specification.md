## Proposed Formula Specifications, Part 1: OHLCV, Returns, SMA, EMA

### OHLCV Pass-Through

- Open = raw Alpaca Open value for the Symbol/Datetime bar
- High = raw Alpaca High value for the Symbol/Datetime bar
- Low = raw Alpaca Low value for the Symbol/Datetime bar
- Close = raw Alpaca Close value for the Symbol/Datetime bar
- Volume = raw Alpaca Volume value for the Symbol/Datetime bar

Rules:

- OHLCV columns must be numeric.
- Open, High, Low, Close, and Volume must be nonnegative.
- Rows with invalid OHLCV values are rejected under the future generation recipe.
- Feature calculations are grouped by Symbol.
- Rows are deterministically sorted by Symbol and Datetime before feature generation.

### Returns

- return_1h = per-symbol Close.pct_change(1)
- log_return_1h = log(Close / Close.shift(1)) per symbol

Rules:

- return_1h input columns = Symbol, Datetime, Close
- log_return_1h input columns = Symbol, Datetime, Close
- grouping = Symbol
- sorting = Symbol, Datetime
- warm-up behavior = first return row per Symbol is NaN
- infinity handling = replace infinity with NaN, then apply warm-up/drop policy
- zero or invalid previous Close = output NaN, then apply warm-up/drop policy

### Simple Moving Averages

- sma_10 = per-symbol rolling mean of Close over 10 bars
- sma_20 = per-symbol rolling mean of Close over 20 bars
- sma_50 = per-symbol rolling mean of Close over 50 bars

Rules:

- input columns = Symbol, Datetime, Close
- grouping = Symbol
- sorting = Symbol, Datetime
- rolling min_periods = window size
- sma_10 min_periods = 10
- sma_20 min_periods = 20
- sma_50 min_periods = 50
- warm-up rows = NaN until the required window is available
- NaN warm-up rows = dropped after feature generation but before split assignment

### Exponential Moving Averages

- ema_12 = per-symbol exponential moving average of Close with span 12
- ema_26 = per-symbol exponential moving average of Close with span 26

Rules:

- input columns = Symbol, Datetime, Close
- grouping = Symbol
- sorting = Symbol, Datetime
- EMA adjust = False
- ema_12 span = 12
- ema_26 span = 26
- minimum warm-up review = REQUIRED_BEFORE_GENERATION_AUTHORIZATION
- NaN handling = any invalid EMA output is handled by the warm-up/drop policy

## Proposed Formula Specifications, Part 2: RSI, MACD, ATR

### RSI

- rsi_14 = 14-period RSI using Wilder smoothing

Proposed standard:

- input columns = Symbol, Datetime, Close
- grouping = Symbol
- sorting = Symbol, Datetime
- price change = Close.diff(1) per symbol
- gain = positive part of price change
- loss = absolute value of negative part of price change
- avg_gain = Wilder-smoothed average gain over 14 bars
- avg_loss = Wilder-smoothed average loss over 14 bars
- relative_strength = avg_gain / avg_loss
- rsi_14 = 100 - 100 / (1 + relative_strength)
- RSI method = Wilder smoothing
- min_periods = 14
- zero avg_loss handling = output 100 when avg_gain is positive and avg_loss is zero
- zero avg_gain and zero avg_loss handling = output NaN, then apply warm-up/drop policy
- infinity handling = replace infinity with NaN except explicit zero-loss RSI rule
- review status = PROPOSED_STANDARD_REQUIRES_REVIEW_BEFORE_GENERATION_AUTHORIZATION

### MACD

- macd = ema_12 - ema_26
- macd_signal = EMA of macd with span 9
- macd_hist = macd - macd_signal

Rules:

- input columns = Symbol, Datetime, Close
- grouping = Symbol
- sorting = Symbol, Datetime
- ema_12 adjust = False
- ema_26 adjust = False
- macd_signal span = 9
- macd_signal adjust = False
- infinity handling = replace infinity with NaN, then apply warm-up/drop policy
- NaN handling = apply warm-up/drop policy after all feature generation
- review status = PROPOSED_STANDARD_REQUIRES_REVIEW_BEFORE_GENERATION_AUTHORIZATION

### ATR

- true_range = max(High - Low, abs(High - previous Close), abs(Low - previous Close))
- atr_14 = 14-period Wilder-style average of true_range

Rules:

- input columns = Symbol, Datetime, High, Low, Close
- grouping = Symbol
- sorting = Symbol, Datetime
- previous Close = Close.shift(1) per symbol
- ATR method = Wilder smoothing
- min_periods = 14
- invalid true_range = output NaN, then apply warm-up/drop policy
- infinity handling = replace infinity with NaN, then apply warm-up/drop policy
- review status = PROPOSED_STANDARD_REQUIRES_REVIEW_BEFORE_GENERATION_AUTHORIZATION

### Time Features

- hour_sin = sin(2*pi*hour_of_regular_session_index / number_of_regular_session_hour_slots)

- day_of_week_sin = sin(2*pi*day_of_week / 5)
- day_of_week_cos = cos(2*pi*day_of_week / 5)

Proposed standard:

- input columns = Symbol, Datetime
- timezone basis = UTC input Datetime mapped to the regular-session calendar for the symbol/date
- regular-session filtering basis = bars whose Datetime falls within market regular session for the symbol/date, expressed in UTC
- hour_of_regular_session_index = zero-based observed regular-session bar index for the symbol/date after sorting
- number_of_regular_session_hour_slots = count of observed regular-session 1h bars for the symbol/date
- day_of_week = Monday 0, Tuesday 1, Wednesday 2, Thursday 3, Friday 4
- early closes/holidays = use observed Alpaca bars; do not synthesize missing bars
- rows outside regular session = rejected before feature generation
- review status = PROPOSED_STANDARD_REQUIRES_REVIEW_BEFORE_GENERATION_AUTHORIZATION

## Missing Sealed Dataset

```text

source_of_truth_issue_category = DATASET_PATH_APPEARS_GITIGNORED_OR_EXCLUDED
```

The missing sealed dataset is the validation-only / no-submit PPO v2 training input expected by the v3.07 package configuration and preflight checks.

It is needed before PPO v2 training because the training input must be fixed, identifiable, and reproducible before any sealed training command, model fitting, model artifact creation, or deployment-readiness decision can be considered.

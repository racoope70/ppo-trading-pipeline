## What Counts as a Trusted Artifact Source

A trusted artifact source is a local, mounted, or manually available artifact location that can be tied to the v3.07/v3.08 source-of-truth chain through evidence.

A source should not be treated as trusted merely because it contains a file with the same filename.

A candidate source must provide enough evidence to evaluate whether it is the sealed dataset expected by:

```text
data/processed/ppo_v2/v3_07_no_submit_training_input.parquet
```

## Candidate Dataset Trust Requirements

A matching filename alone is not enough to trust a candidate dataset.

Any candidate must be checked against as much of the following evidence as available:

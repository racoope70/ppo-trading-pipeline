distinguish an identity mismatch, status mismatch, staged change, Python
version mismatch, Git subprocess failure, guard-installation failure, or
pre-inspection persistence failure.

with `preflight_failed_branch` and a bounded `preflight_exception_class`.
Exception messages are not recorded. The active branch distinguishes Git
checks, guard installation, preflight-state persistence, and
inspection-start-state persistence.

# v1.2 Post-Order Monitoring and Controlled Exit/Rebalance Test

Date: 2026-05-22  
Environment: Alpaca Paper Trading  
Mode: Post-order monitoring / controlled rebalance review

## Purpose

Validate that the paper-trading system can safely monitor and evaluate the existing AMD paper position created during v1.1.

This test checks that the pipeline can handle a non-flat account state.

## Starting State

After v1.1, the account held an AMD paper position:

```text
symbol = AMD
qty = 21.858085
avg_entry = 470.72
open_orders = none
```

## v1.2 Safety Difference

Unlike earlier flat-start checks, v1.2 intentionally allows an open position.

```text
--require-flat-start was not used
--allow-open-positions was used in the pre-trade checklist
```

## Monitoring Chain

```bash
python -m src.paper_trading.paper_trade_dry_run \
  --artifacts-dir models/ppo_models_master

python -m src.paper_trading.evaluate_dry_run \
  --run-dir reports/paper_trading_dry_runs/latest

python -m src.paper_trading.build_execution_plan \
  --run-dir reports/paper_trading_dry_runs/latest

python -m src.paper_trading.risk_controls \
  --run-dir reports/paper_trading_dry_runs/latest

python -m src.paper_trading.paper_trade_loop \
  --run-dir reports/paper_trading_dry_runs/latest

python -m src.paper_trading.pre_trade_checklist \
  --run-dir reports/paper_trading_dry_runs/latest \
  --check-broker \
  --expected-equity 100000 \
  --equity-tolerance-pct 0.05 \
  --allow-open-positions
```

## Interpretation

The v1.2 test validates that the system can operate after the first controlled paper trade.

A passing result means:

```text
existing AMD position was detected
risk controls ran without requiring a flat account
execution plan reflected current position state
paper-order runner remained guarded
broker state was reviewed after the test
controlled sell-reduce rebalance order was submitted
```

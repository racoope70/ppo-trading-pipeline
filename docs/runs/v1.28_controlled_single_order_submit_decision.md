## Interpretation

v1.28 confirms that candidate persistence matters.
A candidate identified in one checkpoint should not automatically carry forward if the next fresh run produces a different trade.
The correct operational response was to stop, document the changed signal, and avoid submitting.

## Guardrails

Do not submit the AMD buy from this v1.28 review run.
Do not submit a candidate merely because risk and checklist pass.
A future controlled submit still requires:

```text

--confirm-run-dir <exact reviewed run dir>

```

## Safety Guarantees

The reporting stack does not:

```text
connect to Alpaca
submit orders
alter broker state
change execution plans
approve trades
replace manual review
```

The reporting stack only reads and writes local reporting artifacts.

## Repository Hygiene

v1.42 and v1.43 established artifact governance:

```text
commit stable docs and curated dashboards
keep generated runtime artifacts local by default
do not commit raw broker/account snapshots by default
never commit secrets
avoid git add .
use explicit git add commands
```

Runtime artifacts under:

```text
reports/
```

are ignored by default.

Curated documentation under:

```text
docs/runs/
docs/workflows/
README.md
PROJECT_CONTEXT.md
```

remains commit-eligible.

## Controlled Submit Separation

A future controlled submit still requires:

```text
fresh dry run

```

The reporting chain is not a submit checkpoint.

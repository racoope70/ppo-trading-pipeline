The artifact receives exactly three fixed positional literals at a future
launch:


literals and the exact complete invocation. The artifact requires:


The later launch commit can advance beyond artifact provenance without changing
the reviewed artifact bytes. A separate exact launch package binds the later
commit and CI run ID to the invocation. That package and explicit user
authorization—not runtime discovery—supply the literals.

`git status --short`, that removed the leading index-space from the expected
tracked modification:


single-record worktree state.

continues to use `.strip()` for `rev-parse` and cached-diff calls. Only
`git status --short` enables the option, which removes terminal newline
characters while preserving the porcelain status prefix.

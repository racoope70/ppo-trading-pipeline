## Policy Scope

The policy defines retention rules for:

```text
workflow documentation
run notes
curated dashboard artifacts
local run artifacts
promoted run evidence
broker/account runtime data
sensitive files
```

## Key Decision

The repository should commit:

```text
stable policies
run notes
README/project context updates
curated dashboards
selected audit summaries
```

The repository should not commit by default:

```text
raw local run directories
transient JSON outputs
raw broker snapshots
environment files
credentials
temporary logs
```

## Curated Artifacts

The policy allows reviewed project-level dashboard artifacts to remain committed:

```text
docs/runs/paper_trading_decision_dashboard.md
docs/runs/paper_trading_decision_dashboard.csv
docs/runs/paper_trading_decision_dashboard_with_state.md
```

These are treated as curated dashboard outputs, not raw runtime artifacts.

## Git Hygiene

The policy warns against broad adds:

```bash
git add .
```

Preferred pattern:

```bash
git add docs/runs/<file>.md
git add docs/workflows/<file>.md
git add README.md
```

## Safety Message

Artifact retention does not authorize trading.

The expected reporting default remains:

```text
decision = NO_SUBMIT
submit_allowed = False
```

A future controlled submit still requires a separate controlled-submit checkpoint.

## Interpretation

v1.42 makes the reporting workflow cleaner by separating durable audit documentation from transient runtime artifacts.
This helps keep the repository readable while preserving the important paper-trading decision trail.

## Exact future command

The following is the single exact command proposed for a later, separately
reviewed and explicitly authorized execution from the repository root. It is
recorded as text only and was not run by this package.

```bash
.venv311/bin/python -c '
from importlib import metadata
from pathlib import Path
import re
import sys

IDENTITY = "ALPACA_PY"
expected = (Path.cwd() / ".venv311" / "bin" / "python").resolve()
actual = Path(sys.executable).resolve()

def emit(version, cardinality, classification):
    print(f"distribution_identity={IDENTITY}")
    print(f"installed_version={version}")
    print(f"result_cardinality={cardinality}")
    print(f"terminal_classification={classification}")
    print("command_count=1")

if actual != expected:
    emit("NOT_INSPECTED", "NOT_INSPECTED", "BLOCK_DOT_VENV311_BOUNDARY_MISMATCH")
    raise SystemExit(1)

try:
    matches = list(metadata.distributions(name="alpaca-py"))
    if len(matches) == 0:
        emit("ABSENT", "ABSENT", "PASS_ALPACA_PY_DISTRIBUTION_ABSENT")
    elif len(matches) > 1:
        emit("WITHHELD", "AMBIGUOUS", "BLOCK_ALPACA_PY_DISTRIBUTION_AMBIGUOUS")
        raise SystemExit(1)
    else:
        version = matches[0].version
        if not isinstance(version, str) or re.fullmatch(r"[A-Za-z0-9][A-Za-z0-9.!+_-]{0,127}", version) is None:
            emit("WITHHELD", "SINGULAR", "BLOCK_INCOMPLETE_SANITIZED_EVIDENCE")
            raise SystemExit(1)
        emit(version, "SINGULAR", "PASS_ALPACA_PY_SINGULAR_IDENTITY_VERSION_ESTABLISHED")
except SystemExit:
    raise
except Exception:
    emit("WITHHELD", "UNKNOWN", "BLOCK_INSPECTION_COMMAND_FAILURE")
    raise SystemExit(1)
'
```

## Bounded behavior

The command uses only the existing `.venv311/bin/python` interpreter and
Python standard-library distribution metadata. The only distribution query is
the allowlisted name `alpaca-py`. The reported identity is the fixed sanitized
category `ALPACA_PY`; the command neither imports Alpaca modules nor enumerates
or reports unrelated distributions.

Output is restricted to exactly these fields:

```text
distribution_identity
installed_version
result_cardinality
terminal_classification
command_count
```

The version is emitted only for one matching distribution and only after a
bounded character/length check. Otherwise it is replaced by `ABSENT`,
`WITHHELD`, or `NOT_INSPECTED`. No exception text, path, package content, or
environment value is emitted.

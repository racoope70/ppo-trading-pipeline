## Safety Control

The system now supports max-plan-age enforcement across:

```text
risk controls
guarded paper-order runner
pre-trade checklist
```

The operational default for the 1-hour strategy is:

```text
--max-plan-age-minutes 90
```

## Expected Behavior

Fresh plan:

```text
plan_not_stale = PASS
execution_plan_not_stale = PASS
```

Stale plan:

```text
plan_not_stale = FAIL
execution_plan_not_stale = FAIL
submit blocked before orders
```

## Submit Guard

Submit mode should use:

```bash
python -m src.paper_trading.paper_trade_loop \
  --run-dir <reviewed_or_filtered_run_dir> \
  --submit-orders \
  --max-plan-age-minutes 90
```

Submit mode should not be used without max-plan-age protection.

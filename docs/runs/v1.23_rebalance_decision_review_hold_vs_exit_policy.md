# v1.23 Rebalance Decision Review / Hold-vs-Exit Policy

Date: 2026-06-08  
Status: Completed  
Mode: Policy / documentation checkpoint  

## Purpose

Create a formal policy for handling model-proposed exits, reductions, or rebalances after a controlled paper-trading submit.

This checkpoint follows:

```text
v1.22 Post-Full-Safety-Stack Submit Monitoring

Background
In v1.21, the system submitted one controlled UNH buy using the full safety stack.
In v1.22, the system recognized the UNH position and proposed a UNH sell rebalance during a no-submit monitoring checkpoint.
The workflow correctly did not submit the sell order.
Files Added

docs/workflows/rebalance_decision_policy.md

Policy Scope
The policy defines:

hold-vs-exit decision rules
immediate-exit caution after recent entries
single-order exit review procedure
multi-order rebalance handling
overtrading risk controls
required submit pattern for approved exits
documentation requirements
guardrails

Key Decision
A model-generated exit signal is not automatically a submit decision.
Any exit or reduce order requires separate review, including:

fresh dry run
risk controls
pre-trade checklist
max-plan-age enforcement
explicit run-dir confirmation
manual approval
broker verification
documentation

v1.22 Decision Carried Forward
The v1.22 UNH sell proposal is documented as:

valid model-generated rebalance proposal
not submitted
held for policy review
not an automatic exit

Interpretation
v1.23 strengthens the paper-trading workflow by separating model signal generation from operational trade approval.
This is important because the system can now:

open controlled paper positions
monitor those positions
detect exit/rebalance signals
avoid accidental overtrading
require review before exits

Guardrails
Do not submit exits automatically.
Do not treat monitoring checkpoints as approval to trade.
Do not submit from stale plans.
Do not submit from multi-order plans without filtering.
Do not move to unattended trading.
Next Step
Recommended next checkpoint:

v1.24 Post-Policy No-Submit Rebalance Review Session

Purpose: run a fresh no-submit cycle under the new v1.23 policy and document whether any proposed rebalance is held, skipped, or eligible for later controlled review.
```

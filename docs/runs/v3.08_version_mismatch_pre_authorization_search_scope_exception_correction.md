## Exception

The version-mismatch pre-authorization check used a repository-wide `rg`
command from the workspace root. Its search target was `.` and its exclusions
did not include `.venv`. As a result, the search incidentally traversed text in
`.venv` packages, contrary to the explicit prohibition on package inspection.
The check is therefore classified `NEEDS_CORRECTION` for procedural scope.

The offending search form was:

```text
rg -n --hidden --glob '!*.pyc' --glob '!.git/objects/**' --glob '!.git/index' "NO_EXECUTION_AUTHORIZED|authorized_current_execution_scope|USED_AND_CONSUMED|no retry|NO_RETRY|remediation|version.mismatch|interpreter|Python 3\.11|planning package" .
```

## Preventive search constraint

All later governed searches for this workstream must avoid a workspace-wide
`.` target and must name the governed Markdown targets explicitly. The allowed
target set is:

```text
PROJECT_CONTEXT.md
docs/runs
docs/reviews
docs/workflows
```

Every such search must be limited to Markdown and must defensively exclude
`.venv`, `.git`, `artifacts`, `data`, source directories, and package
directories. A compliant general form is:

```text
rg -n --glob '!.venv/**' --glob '!.git/**' --glob '!artifacts/**' --glob '!data/**' --glob '!src/**' --glob '!source/**' --glob '!packages/**' --glob '*.md' 'SEARCH_PATTERN' PROJECT_CONTEXT.md docs/runs docs/reviews docs/workflows
```

Naming the exact governed Markdown files is preferred when the required record
set is already known.

The future SIP Feed Investigation Planning document may evaluate only:

- SIP historical-data availability questions;
- SIP entitlement, cost, and licensing constraints;
- whether SIP should be treated as a separate contract-change investigation;
- the exact prospective SIP investigation contract;
- how SIP and IEX evidence would remain isolated;
- what future comparison would be allowed;
- evidence and provenance requirements;
- fail-closed criteria; and
- what later authorization would be required before any SIP API call or data access.

## 6. Four-level separation

1. The pathway decision selected the SIP planning direction only.
2. SIP Feed Investigation Planning Authorization authorizes a planning document only.
3. SIP Feed Investigation Planning may define a possible future investigation contract only.
4. SIP Feed Investigation Execution would require a later separate authorization before any SIP access, Alpaca client creation, API call, market-data fetch, or data comparison.

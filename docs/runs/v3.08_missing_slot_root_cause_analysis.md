## 5. Expected-slot reconstruction method

No new contract was introduced. The analysis used the pinned `exchange-calendars==4.13.2` XNYS schedule and the governed implementation in `src/ppo_v2_market_calendar.py`.

For each session in the canonical window `[2023-01-03T14:30:00Z, 2025-06-30T20:00:00Z)`, the method:

1. reads the timezone-aware XNYS session open and close;
2. ceilings the session open to the next whole UTC hour;
3. emits hourly open timestamps only while `timestamp + 1 hour <= session_close`;
4. excludes timestamps outside the canonical window; and
5. compares each symbol's unique observed UTC timestamps to that common expected grid.

This is the existing whole-interval-containment rule: `session_open <= t` and `t + 1 hour <= session_close`. Holidays produce no expected slots, and early closes use the pinned XNYS close.

```text
calendar_library = exchange_calendars
calendar_version = 4.13.2
calendar_identifier = XNYS
bar_timestamp_semantics = OPEN_TIMESTAMP
bar_interval = [t, t + 1 hour)
expected_slot_derivation = PINNED_XNYS_SCHEDULE_PLUS_PROVIDER_ALIGNED_HOURLY_TIMESTAMPS_SATISFYING_WHOLE_INTERVAL_CONTAINMENT
expected_first_slot = 2023-01-03T15:00:00+00:00
expected_last_slot = 2025-06-30T19:00:00+00:00
```

## 7. Cross-symbol pattern assessment

```text
missing_timestamps_identical_across_all_six_symbols = YES
missing_timestamp_union_count = 11
missing_timestamp_intersection_count = 11
```

Every missing timestamp is shared by every governed symbol. This is inconsistent with isolated ticker-level illiquidity or a symbol-specific raw-data defect and instead points to a common feed, provider, or upstream retrieval-completeness event.

The affected sessions are ordinary full XNYS sessions, not early closes. Both are interior to the governed request window, so the pattern is not a request-start or request-end boundary effect. March 10, 2025 follows the daylight-saving transition, but the pinned XNYS schedule correctly changes the UTC session from 14:30–21:00 to 13:30–20:00 and applies the same governed whole-hour rule used throughout the dataset. The December occurrence has no DST transition. The file uses timezone-aware UTC timestamps, and expected slots are observed normally outside the two affected session portions. These facts do not support a timestamp-normalization or general calendar-slot construction defect.

No duplicate symbol/timestamp rows exist. Raw timestamps outside the final expected grid are expected to include warmup rows and partial session-edge/provider-aligned bars; they do not account for the 11 expected timestamps that are absent across all symbols.

## Core Audit Questions

```text
Were the selected PPO artifacts strong models or merely available artifacts?
Did each selected model beat buy-and-hold after costs?
Did each selected model beat a cash/no-trade baseline?
Were results stable across adjacent walk-forward windows?
Was model selection overly dependent on a single Sharpe-ranked window?
Were embargo/leakage controls sufficient by the current standard?
Were transaction costs, slippage, and turnover handled conservatively?
Did live no-submit behavior support or weaken the original validation case?
Did the candidate set show stability or multi-order instability?
Would the current PPO baseline be promoted today under the stricter standard?
```

```text
Passing infrastructure tests does not prove trading edge.
A model cannot be promoted based only on artifact availability.
A model cannot be promoted based only on Sharpe.
A model cannot be promoted based only on feature importance.
A model cannot be promoted from a multi-order unstable no-submit pattern.
Controlled submit requires a separate future checkpoint.
Hybrid deployment requires a separate future checkpoint.
```

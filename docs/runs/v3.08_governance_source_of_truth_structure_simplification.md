# v3.08 Governance Source-of-Truth Structure Simplification

## 1. Purpose

- `PROJECT_CONTEXT.md` remains the controlling source of truth.
- `PROJECT_CONTEXT.md` now tracks broad active section/state and authorization boundary instead of exact micro-checkpoint sequencing.
- `milestone_review_reference_map.md` remains roadmap/navigation/reference material and does not track the current checkpoint.
- Exact checkpoint chronology comes from Git history and latest pushed run/review records.
- `future_validation_training_reference_map.md` remains guidance only.

## Safety Control

Submit mode now requires:

```text
--confirm-run-dir <exact run dir>
```

The confirmation must match `--run-dir`.

## Required Submit Pattern

```bash
python -m src.paper_trading.paper_trade_loop \
  --run-dir <reviewed_or_filtered_run_dir> \
  --submit-orders \
  --max-plan-age-minutes 90 \
  --confirm-run-dir <reviewed_or_filtered_run_dir>
```

## Expected Behavior

Missing confirmation:

```text

```

Mismatched confirmation:

blocked before loading/submitting orders

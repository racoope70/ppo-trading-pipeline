environment exposes a compatible `alpaca.data` import surface containing the
four required symbols. Before any technical action, a later separately
authorized package-remediation plan would need to define the exact package
identity, version constraint, installation command, verification boundary,
rollback approach, and evidence record.

This planning record does not select a package or version and does not

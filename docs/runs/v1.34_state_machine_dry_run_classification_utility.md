## Utility Behavior

The utility reads a paper-trading run directory and classifies it into one of the decision states:

```text
ABORTED_INVALID_FRESH_CYCLE
NO_CANDIDATE_HOLD
SINGLE_NEW_CANDIDATE
CHANGED_CANDIDATE
PERSISTENT_REVALIDATED_CANDIDATE
MULTI_ORDER_PLAN
FILTERED_CANDIDATE_REVIEW
```

The utility reports:

```text
state
decision
reason
orders_required
buy_count
sell_count
candidate rows
submit_allowed
```

## Read-Only Safety

The utility only reads local artifacts:

```text
dry_run_summary.json
execution_plan_summary.json
execution_plan.csv
```

It does not submit orders.
It does not call Alpaca.
It does not modify broker state.

## CLI Example

```bash
python -m src.paper_trading.classify_decision_state \
  --run-dir reports/paper_trading_dry_runs/latest \
  --prior-symbol AMD \
  --prior-side buy
```

Expected output for a no-candidate hold state:

```text
state: NO_CANDIDATE_HOLD
decision: NO_SUBMIT
orders_required: 0
submit_allowed: False
Candidates:
(none)
```

## JSON Output

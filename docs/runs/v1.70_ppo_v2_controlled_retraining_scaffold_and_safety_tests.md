## Forbidden Execution Fields

The following fields must remain empty unless a later checkpoint explicitly authorizes execution:

* `training_command`
* `dataset_generation_command`

* `paper_order_command`

## Forbidden Model Input Columns

The following columns must remain excluded from PPO v2 model inputs:

* `Target`
* `Return`
* `Datetime`
* `Symbol`

Legacy artifact roots include:


The v1.70 scaffold does not create any generated path contents.

# v1.36 Paper-Trading Pipeline Classification Hook / No-Submit

Date: 2026-06-10  
Status: Completed

## Purpose

Add a post-checklist decision-state classification hook that writes a local decision-state report into the reviewed paper-trading run directory.

This checkpoint integrates the v1.35 decision-state report writer into the paper-trading workflow as a post-checklist hook.

No broker connection is required.

No orders were submitted.

## Hook Behavior

The hook runs after the pre-trade checklist and writes:

```text
decision_state_report.json
```

into the target run directory.

The hook requires this artifact by default:

```text
pre_trade_checklist_report.json
```

This keeps the hook explicitly post-checklist.

## CLI Usage

```bash
python -m src.paper_trading.pipeline_decision_state_hook \
  --run-dir reports/paper_trading_dry_runs/latest \
  --prior-symbol AMD \
  --prior-side buy
```

## Safety Design

The hook:

```text
does not connect to Alpaca
does not submit orders
does not alter broker state
does not change execution plans
does not approve trades
```

It only reads local run artifacts and writes a local JSON report.

## 4. Review standard

This review distinguishes four different questions:

1. Was the bounded SIP execution properly authorized?
2. Did the execution remain within its authorization?
3. Did the execution reach the SIP API and test provider coverage?
4. Did the execution produce evidence supporting a SIP candidate, contract replacement, or downstream dataset work?

A compliant fail-closed execution may pass governance review even when the technical recovery question remains unanswered.

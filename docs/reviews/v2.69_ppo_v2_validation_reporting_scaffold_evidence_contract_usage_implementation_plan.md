## Implementation Plan Finding

The v2.68 authorization decision allows only a future separate implementation plan checkpoint.

v2.69 defines that plan.

The future implementation must add only a read-only usage adapter around the existing v2.59 evidence contract.

The future adapter must accept a static evidence manifest and return only a pass/fail EvidenceContractResult.

The future adapter must not compute trading metrics, generate reports, fetch data, run PPO training, write artifacts, submit orders, promote models, authorize controlled submit, or unblock PPO + RF / PPO + XGBoost.
